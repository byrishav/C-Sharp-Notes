# 1. Arithmetic operators

> 1. Arithmetic operators in C# are operators used to perform basic mathematical calculations on numeric values or variables.
> 2. They allow us to perform operations such as addition, subtraction, multiplication, division, and finding the remainder of a division.
### 2. Types of Arithmetic Operators

|Operator|Name|Purpose|Example|Result|
|---|---|---|---|---|
|`+`|Addition|Adds two values|`10 + 5`|`15`|
|`-`|Subtraction|Subtracts one value from another|`10 - 5`|`5`|
|`*`|Multiplication|Multiplies two values|`10 * 5`|`50`|
|`/`|Division|Divides one value by another|`10 / 5`|`2`|
|`%`|Modulus|Returns the remainder after division|`10 % 3`|`1`|
|`++`|Increment|Increases a variable by 1|`a++`|Depends on `a`|
|`--`|Decrement|Decreases a variable by 1|`a--`|Depends on `a`|
# 2. Relational Operators

> 1.Relational or comparison operators in C# are operators used to compare two values or expressions.
> 2. They determine the relationship between the values and return a Boolean result: `true` if the comparison is satisfied or `false` otherwise.

### 2. Types of Relational and Comparison Operators

| Operator | Name                     | Purpose                                                             | Example    | Result |
| -------- | ------------------------ | ------------------------------------------------------------------- | ---------- | ------ |
| `==`     | Equal to                 | Checks whether two values are equal                                 | `10 == 10` | `true` |
| `!=`     | Not equal to             | Checks whether two values are different                             | `10 != 5`  | `true` |
| `>`      | Greater than             | Checks whether the left value is greater than the right             | `10 > 5`   | `true` |
| `<`      | Less than                | Checks whether the left value is less than the right                | `5 < 10`   | `true` |
| `>=`     | Greater than or equal to | Checks whether the left value is greater than or equal to the right | `10 >= 10` | `true` |
| `<=`     | Less than or equal to    | Checks whether the left value is less than or equal to the right    | `5 <= 10`  | `true` |

# 3. Logical Operators

>1. Logical operators in C# are used to combine, evaluate, or reverse Boolean conditions. 
>2. They return a Boolean result (`true` or `false`) and are commonly used in decision-making statements such as `if`, `else`, and loops. 
>3. They help us check multiple conditions together.

#### 2. Types of Logical Operators

|Operator|Name|Purpose|Example|Result|
|---|---|---|---|---|
|`&&`|Logical AND|Returns `true` when both conditions are true|`(10 > 5) && (8 > 3)`|`true`|
|`\\|\\|`|Logical OR|Returns `true` when at least one condition is true|`(10 < 5) \\|\\| (8 > 3)`|`true`|
|`!`|Logical NOT|Reverses the Boolean result|`!(10 > 5)`|`false`|

# 5.Increment and Decrement Operators

>1. Increment and decrement operators in C# are unary operators used to increase or decrease the value of a numeric variable by one.
>2. The increment operator (`++`) increases a variable's value by 1, while the decrement operator (`--`) decreases it by 1.
>3. Both operators support prefix and postfix forms, which determine when the updated value is produced in an expression.

#### 2. Types of Increment and Decrement Operators

| Operator | Name           | Purpose                                           | Example | Result (if `a = 5`)    |
| -------- | -------------- | ------------------------------------------------- | ------- | ---------------------- |
| `++a`    | Pre-increment  | Increments first, then produces the updated value | `++a`   | `6`                    |
| `a++`    | Post-increment | Produces the current value first, then increments | `a++`   | `5` (expression value) |
| `--a`    | Pre-decrement  | Decrements first, then produces the updated value | `--a`   | `4`                    |
| `a--`    | Post-decrement | Produces the current value first, then decrements | `a--`   | `5` (expression value) |
# 6. Bitwise Operators 

Bitwise operators in C# are operators that perform operations directly on the individual bits of integer values. They work on the binary representation of numbers and are commonly used for bit manipulation, flags, low-level programming, and optimizing certain operations.

#### 2. Types of Bitwise Operators

|Operator|Name|Purpose|Example|Result|
|---|---|---|---|---|
|`&`|Bitwise AND|Sets a result bit to `1` only when both corresponding bits are `1`|`5 & 3`|`1`|
|`\\|`|Bitwise OR|Sets a result bit to `1` when at least one corresponding bit is `1`|`5 \\| 3`|`7`|
|`^`|Bitwise XOR|Sets a result bit to `1` when corresponding bits are different|`5 ^ 3`|`6`|
|`~`|Bitwise NOT|Inverts every bit of the operand|`~5`|`-6` for `int`|
|`<<`|Left shift|Shifts bits to the left|`5 << 1`|`10`|
|`>>`|Right shift|Shifts bits to the right|`5 >> 1`|`2`|
# 7. Ternary Operator

The ternary operator (`?:`) in C# is a conditional operator used to evaluate a condition and return one of two values depending on whether the condition is `true` or `false`. It is a shorter alternative to an `if-else` statement when we need to choose between two expressions.

```java
condition ? expressionIfTrue : expressionIfFalse;
```

# 8. `is` vs `as` 

>In C#, `is` and `as` are operators used when working with types, particularly when checking or converting reference types.

- `is` operator: Checks whether an object is compatible with a specified type and returns a Boolean result (`true` or `false`). It can also declare a variable of the matched type using pattern matching.

- `as` operator: Attempts to convert an object to a compatible reference or nullable type. If the conversion fails, it returns `null` instead of throwing an exception for that failed conversion.


## 2. Difference between `is` and `as`

|Basis|`is`|`as`|
|---|---|---|
|Purpose|Checks type compatibility.|Attempts a type conversion.|
|Return value|`true` or `false` for a Boolean type check.|Converted reference or nullable value, or `null`.|
|Failed check/conversion|Returns `false` for an unsuccessful type check.|Returns `null` for an unsuccessful supported conversion.|
|Common use|Checking an object's type before using it.|Safely attempting a reference-type conversion.|
|Example|`obj is string`|`obj as string`|

# 9. Null-Coalescing Operator (`??`) in C#

>The null-coalescing operator (`??`) in C# is used to provide a default value when an expression evaluates to `null`. It returns the left-hand operand if it is not null; otherwise, it returns the right-hand operand. It helps us handle null values concisely without writing an explicit `if-else` statement.

## 2. Syntax

```
result = value ?? defaultValue;
```

- If `value` is not `null`, its value is assigned to `result`.
    
- If `value` is `null`, `defaultValue` is assigned to `result`.

# 10. Null-conditional operator (`?.`)

>The null-conditional operator (`?.`) in C# allows us to access a member of an object only if the object is not `null`. If the object is `null`, the expression returns `null` instead of throwing a `NullReferenceException`.

## 2. Simple explanation

- It prevents errors when an object might be `null`.
    
- If the object is not null, its property or method is accessed normally.
    
- If the object is null, the operation is skipped and the result is `null` (or a nullable value for value-type members).
    
- It makes code shorter and cleaner than writing an explicit `if` condition.
