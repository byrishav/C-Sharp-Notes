#  1. CLR (Common Language Runtime)

>1. The [Common Language Runtime](https://www.geeksforgeeks.org/c-sharp/common-language-runtime-clr-in-c-sharp/) (CLR) is the ==execution environment== of the .NET platform
>2. that runs managed code. 
>3. and provides services such as ==memory management==, garbage collection, exception handling, and security.

# 2. CTS (Common Type System)

>1. CTS stands for Common Type System.
>2. It defines how data types are declared, used, and managed in .NET
>3. It ensures that ==different .NET languages==, such as C# and VB.NET, can work with the same data types.

# 3. CLS (Common Language Specification)

>1. CLS stands for Common Language Specification. 
>2. It is a set of rules that .NET languages follow to ensure they can share code and work together. 
>3. It helps languages like C# and VB.NET communicate with each other.

Example: If you create a class in C# that follows CLS rules, it can be used by a VB.NET application.

# 4. CIL (Common Intermediate Language)/MSIL

>1. CIL (Common Intermediate Language)
>2. It is an intermediate, CPU-independent ==**instruction set**== generated by the .NET compiler 
>3. from source code written in languages such as C#. 
>4. These instructions are stored in an assembly, such as a `.dll` or `.exe`, and are later converted into native machine code by the JIT (Just-In-Time) compiler.

MSIL (Microsoft Intermediate Language) is the older name commonly used for CIL.

# 5. JIT

>1. The JIT (Just-In-Time) Compiler 
>2. it is a component of the .NET runtime
>3. that converts CIL/MSIL (Intermediate Language) instructions into native machine code at runtime
>4. so the processor can execute them.

### Step-by-step explanation

1. Compilation: The C# compiler converts source code into CIL/MSIL.
    
2. Storage: The intermediate code is stored in a .NET assembly.
    
3. JIT compilation: When a method needs to execute, the JIT compiles its IL into native machine code.
    
4. Execution: The CPU executes the generated machine code.
    
5. Reuse: The compiled native code can generally be reused for subsequent calls to that method during the process, rather than recompiling it every time.
