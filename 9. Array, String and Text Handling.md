# Arrays

## Definition

> 1. An array in C# is a collection of elements of the same data type stored under a single variable name.
> 2. It has a fixed size, and each element is accessed using an index starting from 0.

## One Dimensional Array 

>1. A one-dimensional array in C# is a collection of elements of the same data type arranged in a single row. 
>2. Each element is accessed using a single index, starting from `0`.

## Two Dimensional Array 

 > 1. A multidimensional array in C# is an array that stores elements of the same data type in two or more dimensions, such as rows and columns. 
 > 2. Each element is accessed using multiple indexes.

## Jaggered Array 

>1. A jagged array in C# is an array of arrays in which each inner array can have a different length. 
>2. It is useful when each row needs to store a different number of elements.

# Strings

## Definition

> 1. A string in C# is a sequence of characters used to store and manipulate text.
> 2. It is represented by the `string` keyword and is immutable, meaning its value cannot be changed after creation.

### Key points

1. Stores text: A string can contain letters, numbers, symbols, and spaces.
    
2. Immutable: Once created, the string's contents cannot be changed; operations that modify text produce a new string.
    
3. Reference type: `string` is a reference type in C#.
    
4. Double quotes: String values are written inside double quotes.
    
5. Built-in methods: C# provides methods such as `ToUpper()`, `ToLower()`, `Substring()`, `Replace()`, and `Contains()`.

## String manipulation

### Important string methods

| Method         | Purpose                           | Example result                         |
| -------------- | --------------------------------- | -------------------------------------- |
| `ToUpper()`    | Converts to uppercase             | `"hello"` → `"HELLO"`                  |
| `ToLower()`    | Converts to lowercase             | `"HELLO"` → `"hello"`                  |
| `Trim()`       | Removes whitespace from both ends | `" Hi "` → `"Hi"`                      |
| `Replace()`    | Replaces text                     | `"cat".Replace("c","b")` → `"bat"`     |
| `Contains()`   | Checks whether text exists        | `"Hello".Contains("ell")` → `true`     |
| `Substring()`  | Extracts part of a string         | `"Hello".Substring(1,3)` → `"ell"`     |
| `IndexOf()`    | Finds the first matching position | `"Hello".IndexOf("l")` → `2`           |
| `StartsWith()` | Checks the beginning              | `"Hello".StartsWith("He")` → `true`    |
| `EndsWith()`   | Checks the ending                 | `"Hello".EndsWith("lo")` → `true`      |
| `Split()`      | Divides a string into parts       | `"A,B".Split(',')` → `["A","B"]`       |
| `Join()`       | Combines strings with a separator | `string.Join("-", "A", "B")` → `"A-B"` |

# StringBuilder

>1. StringBuilder in C# is a class used to create and modify strings efficiently, 
>2. especially when performing frequent changes.
>3. Unlike `string`, it allows modifications without creating a new string object for every operation.

## String vs String Builder

|Feature|`string`|`StringBuilder`|
|---|---|---|
|Mutability|Immutable|Mutable|
|Modification|Creates a new string when modified|Modifies its contents|
|Performance|Can be less efficient for frequent modifications|Often more efficient for frequent modifications|
|Namespace|`System`|`System.Text`|
|Memory usage|May create multiple string objects during repeated changes|Reuses its internal buffer when possible|
|Best use|Fixed text or a small number of changes|Repeated text modifications, especially in loops|
|Common operations|`Replace()`, `Substring()`, `ToUpper()`|`Append()`, `Insert()`, `Replace()`, `Remove()`|
|Thread safety|Strings are immutable, but variable references can still be reassigned|Not thread-safe by default|
|Conversion|Already a string|Use `ToString()` to get a `string`|
