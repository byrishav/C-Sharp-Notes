# Variables

>A variable in C# is a named memory location used to store data that can be accessed and, depending on its declaration, updated during program execution.

## constant
A constant in C# is a variable-like identifier whose value must be assigned at declaration and cannot be changed during program execution. It is declared using the `const` keyword.

### Key points

1. Uses `const`: The keyword declares a constant.
    
2. Cannot be changed: Its value cannot be reassigned after declaration.
    
3. Must be initialized: A constant must receive its value when declared.
    
4. Compile-time value: Its value must be known at compile time.
    
5. Common use: Useful for fixed values such as mathematical constants or fixed configuration values.

## Data Types

>1. Data types in C# define what kind of data a variable can store, such as numbers, characters, text, or objects.
>2. They also determine the operations that can be performed on that data.

C# data types are broadly divided into two categories: value types and reference types.

## 1. Value Types vs Reference Types

|Feature|Value Types|Reference Types|
|---|---|---|
|Stores|The actual value|A reference to an object|
|Examples|`int`, `char`, `bool`, `double`, `struct`, `enum`|`string`, arrays, classes, interfaces, delegates|
|Assignment|Copies the value|Copies the reference by default|
|Effect of assignment|Changing one variable usually doesn't affect the other|Both variables can refer to the same object|
|Null|Cannot be `null` by default; nullable value types can be|Can be `null`|
|Memory|Often stored inline or on the stack, depending on context|Objects are typically allocated on the managed heap|

### 2. Example of a Value Type

```
int a = 10;
int b = a;

b = 20;

Console.WriteLine(a); // 10
Console.WriteLine(b); // 20
```

### 3. Example of a Reference Type

```
class Student
{
    public string name = "";
}

Student s1 = new Student();
s1.name = "Rishav";

Student s2 = s1;
s2.name = "Rahul";

Console.WriteLine(s1.name); // Rahul
Console.WriteLine(s2.name); // Rahul
```

## 4. Common Data Types

|Value Types|Reference Types|
|---|---|
|`int` — integer numbers|`string` — text|
|`long` — large integer numbers|`object` — base type for all C# types|
|`float` — single-precision decimal numbers|`dynamic` — type checks are deferred to runtime|
|`double` — double-precision numbers|Arrays — collections of elements|
|`decimal` — high-precision decimal values, useful for money|Classes — user-defined reference types|
|`char` — one UTF-16 code unit|Interfaces — define contracts|
|`bool` — `true` or `false`|Delegates — references to callable methods|
|`struct` — user-defined value type||

## Primitive vs Non-Primitive Types
Interview definition: Primitive data types are the basic built-in types used to store simple values, such as numbers, characters, and Boolean values. Non-primitive types are types used to represent more complex data, such as strings, arrays, classes, and objects.

### Primitive vs Non-Primitive Types

|Feature|Primitive Types|Non-Primitive Types|
|---|---|---|
|Meaning|Basic data types|Types used to represent more complex data|
|Examples|`int`, `char`, `bool`, `double`, `float`|`string`, arrays, classes, interfaces|
|Purpose|Store simple values|Store text, collections, objects, or define structures|
|In C#|Usually built-in value types|Can be reference types or user-defined value types|

## 1. Implicit Conversion in C#

Interview definition: Implicit conversion is the automatic conversion of one data type into another by the compiler when the conversion is safe and does not require explicit instructions.

Example:

```
int a = 10;
double b = a;

Console.WriteLine(b); // 10
```

Explanation:

- `a` is an `int`, and `b` is a `double`.
    
- C# automatically converts the integer into a double.
    
- No casting syntax is required.
    
- The conversion preserves the value.
    

Another example:

```
int num = 100;
long result = num;
```

An `int` can be converted implicitly to a `long`.

## 2. Explicit Conversion in C#

Interview definition: Explicit conversion is the conversion of one data type into another that requires the programmer to specify the conversion, usually because information could be lost or the conversion is not guaranteed to succeed.

Example:

```
double a = 10.75;
int b = (int)a;

Console.WriteLine(b); // 10
```

Explanation:

- `a` is a `double`.
    
- `(int)` explicitly converts it to an integer.
    
- The decimal part is removed; it is not rounded.
    
- Therefore, `10.75` becomes `10`.
    

Another example:

```
long a = 100;
int b = (int)a;
```

This conversion is explicitly specified. If the `long` value is outside the `int` range, the result may be incorrect due to overflow, depending on the context.

## 3. Type Casting in C#

Interview definition: Type casting is the process of converting a value from one data type to another. In C#, it is commonly performed using a cast operator, such as `(int)`, or through conversion methods.

Example:

```
double price = 99.99;
int wholePrice = (int)price;

Console.WriteLine(wholePrice); // 99
```

Here, `(int)` is the cast operator used for explicit conversion.

### Type casting vs conversion methods

C# also provides methods such as `Convert.ToInt32()` and `int.Parse()`.

```
string value = "123";

int a = int.Parse(value);
int b = Convert.ToInt32(value);

Console.WriteLine(a); // 123
Console.WriteLine(b); // 123
```

Note: `int.Parse()` and `Convert.ToInt32()` can throw exceptions for invalid input. For user input, `int.TryParse()` is often safer.

## Difference between implicit and explicit conversion

|Feature|Implicit Conversion|Explicit Conversion|
|---|---|---|
|Meaning|Automatic conversion|Programmer specifies the conversion|
|Syntax|No cast required|Usually uses `(type)`|
|Risk of data loss|Generally designed to preserve values|May lose information or fail|
|Example|`double b = a;` where `a` is `int`|`int b = (int)a;` where `a` is `double`|

Remember for interviews:

- Implicit: The compiler converts automatically.
    
- Explicit: The programmer specifies the conversion.
    
- Type casting: The act of converting a value from one type to another; `(int)` is a common example of explicit casting.
