

## 2. What is Garbage Collection?

Interview answer: Garbage Collection is a feature in C# that automatically frees memory used by objects that are no longer needed.

Key points:

1. It helps manage memory automatically.
    
2. It cleans up objects that are no longer reachable.
    
3. It reduces the need to manually manage object memory.
    
4. The Garbage Collector decides when to perform cleanup; it does not necessarily happen immediately.
    

Example: If an object is no longer being used or referenced, the Garbage Collector can eventually clean it up.

## 3. What is the difference between `const` and `readonly`?

Interview answer: 
Both are used for values that should not change after they are set,
but they differ in
==when the value can be assigned==.

Key points:

1. `const` must be assigned when it is declared.
    
2. `const` values must be known at compile time.
    
3. `readonly` can be assigned when declared or inside a constructor.
    
4. Both prevent reassignment after their allowed initialization.
    


## 4. What does `static` mean?

Interview answer: `static` means a member belongs to the class itself rather than to a particular object.

Key points:

1. A static variable is shared by all objects of that class.
    
2. A static method can be called using the class name.
    
3. A static class cannot be instantiated using `new`.
    
4. Static members can be accessed without creating an object, subject to their access rules.
    

Example:

```
class Student
{
    public static int count = 0;
}

Console.WriteLine(Student.count);
```

Here, `count` belongs to the `Student` class.

## 9. What is the difference between `==` and `.Equals()`?

Interview answer: Both are used to compare values or objects, but their behavior depends on the type and how equality is implemented.

Key points:

1. `==` is an operator.
    
2. `.Equals()` is a method.
    
3. For strings, both normally compare the text.
    
4. For some other types, `==` may compare references while `.Equals()` may compare values.
    

Example:

```
string a = "Hello";
string b = "Hello";

Console.WriteLine(a == b);       // True
Console.WriteLine(a.Equals(b));  // True
```

Remember: Their behavior is type-dependent; do not assume they always work identically.
