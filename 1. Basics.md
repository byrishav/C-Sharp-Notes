# 2. What is .NET Framework (or .NET) and how does it work?

>1. **.NET** is a ==software development platform== developed by Microsoft for creating and running applications across different platforms. 
>2. It provides the ==runtime, libraries, and tools== required to develop applications using languages such as C#.

- ****CLR:**** Manages code execution, memory, garbage collection, and exceptions.
- ****BCL:**** Provides reusable APIs for collections, file handling, networking, and other common operations.
- ****Language Support:**** Allows languages such as C#, F#, and Visual Basic to work with the same .NET platform.

### 2. Reference Types

They store a reference to an object.

| Data type   | Example                                    |
| ----------- | ------------------------------------------ |
| `string`    | `string name = "Rishav";`                  |
| `object`    | `object data = 100;`                       |
| `array`     | `int[] numbers = { 1, 2, 3 };`             |
| `class`     | `Student student = new Student();`         |
| `interface` | Defines a contract for classes and structs |
| `delegate`  | Holds references to methods                |

# Value Types vs Reference Types

> 1. Value types store their data directly, while reference types store a reference to an object. 
> 2. When we assign a value type variable to another variable, its value is copied.
> 3. When we assign a reference type variable to another, the reference is copied,
> 4. so both variables can refer to the same object


| Value Types                                         | Reference Types                         |
| --------------------------------------------------- | --------------------------------------- |
| Store values directly.                              | Store references to objects.            |
| Assignment copies the value.                        | Assignment copies the reference.        |
| Variables have independent copies after assignment. | Variables may refer to the same object. |
| Examples: `int`, `bool`, `struct`                   | Examples: `class`, arrays, `string`     |

## 1. Implicit Conversion (Automatic)

C# automatically converts a value to another compatible type when the conversion is safe.

## 2. Explicit Conversion (Type Casting)

When a conversion may lose information, you often need to specify the target type using a cast.

# Type casting

> 1. Type casting in C# is the process of explicitly converting a value from one data type to another by specifying the target type. 
> 2. It is commonly used when an automatic conversion is not allowed or when we want to control the conversion.

# Boxing 

> 1. Boxing in C# is the process of converting a ==value type== into the `object` type.
> 2. During boxing, the value is wrapped inside an object.

# Unboxing 

> 1. Unboxing in C# is the process of extracting a value type from an object that contains a previously boxed value. 
> 2. It requires an explicit cast.

Jump Statements in C# are used to change the normal flow of program execution.
